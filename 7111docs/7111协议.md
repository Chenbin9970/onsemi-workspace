# 7111 参数写协议

> 源文件：`7111协议.doc`（WPS Office 生成，13 页）
> 本文档由 `.doc` 转换而来，逐参数列出 I2C 两帧写命令序列及字段注释。

## 帧格式说明

参数写入采用**两帧组合**：

**帧 1（定位/块选择）**：`14` + `05` + 功能号 + 程序号 + 地址高字节 + 地址低字节 + `CRC高字节` + `CRC低字节`
- `14` = I2C 从机地址（写方向）
- `05` = 定位命令
- 功能号：参数所属功能块（见下）

**帧 2（数据写）**：`14` + `08` + 个数 + 数据… + `CRC高字节` + `CRC低字节`
- `08` = 数据写命令
- 个数：数值字节数（多数参数为 `03`，AGCO Output Limit 为 `06`）

> **校验（CRC）**：`CRC16_CCITT_FALSE`，poly `0x1021`，init `0xFFFF`。CRC 覆盖**不含 I2C 地址字节 `0x14`** 的整条载荷（帧 1 为 `05 功能号 程序号 地址高 地址低`；帧 2 为 `08 个数 数据…`），结果**高字节在前**发送。已按此算法逐一重算（各条目帧尾即正确校验值）。

**数值编码**：
- 无符号正数：大端 24 位（例 `00 1F 40` = 8000，`00 04 4C` = 1100）
- 负数：补码存于首字节（例 `EC 00 00` = -20，`F6 00 00` = -10）
- 特殊编码：AGCO Gain / Output Limit 见对应条目注释

## AGCO（功能号 07 / 08，程序号 01）

### Wideband AGCO Gain

```
14 05 07 01 00 19 D7 5E
14 08 00 03 E3 FD 71 6A C4
14 05 07 01 00 2A D1 6E
14 08 00 03 E3 FD 71 6A C4
```
（16 通道逐一写入）
```
14 05 07 01 01 18 F4 4E
14 08 00 03 E3 FD 71 6A C4
14 05 08 01 00 00 80 A8
14 08 00 06 00 00 19 04 27 04 7B 4D
```

| 字段 | 值 |
|------|-----|
| 功能号 | 07、08 |
| 程序号 | 01 |
| 地址 | `0019` = 0x19 + 0x11*0(通道)；`002A` = 0x19 + 0x11*1(通道)；`0118` = 0x19 + 0x11*15(通道)；`0000`（功能号 08） |
| 个数 | 0003（功能号 07）；0006（功能号 08） |
| 数值（功能号 07） | `E3 FD 71`：`0xE3` = 252-25（setvalue=25db）；`0xFD 0x71` 补充固定值 |
| 数值（功能号 08） | `00 00 19 04 27 04`：`00 00` setvalue；`04 27 04` = 0x2A85*setvalue + ?（setvalue=25db） |

> 功能号 07 每通道地址步进 `0x11`（17），通道 0~15。功能号 08 为整体参数，地址 0000。

### Wideband AGCO Output Limit

```
14 05 08 00 00 00 B7 98
14 08 00 06 00 00 00 00 00 00 90 A8
```

| 字段 | 值 |
|------|-----|
| 功能号 | 08 |
| 程序号 | 00 |
| 地址 | 0000 |
| 个数 | 0006 |
| 数值 | `00 00 00 00 00 00` → setvalue：0db；`FF FF FF FF D5 7B` → setvalue：1db |

编码说明：
- `FF FF FF` = 0 - setvalue
- `FF D5 7B` = `FF D5 7B` * setvalue
