# 打印口（UART 调试打印）说明

> **2026-08-27**：打印口从 DIO5 改到 **DIO12**。修改的是 SDK pack 里的 `printf.c`（`UART_TX=12`），保证 Eclipse 重新生成 makefile 也生效。

## 一、概述

7160test 工程的调试打印走 **RSL10 硬件 UART**（115200），通过 `PRINTF()` 宏输出。

- 总开关：`app.h` 的 `DEBUG_UART_ENABLE`（当前**打开**）
- 打印口（UART TX）：**DIO12**
- UART RX：DIO4
- 波特率：115200（8N1）

## 二、打印链路

```
PRINTF(...)  →  printf(...)（printf.h，DEBUG_UART_ENABLE 时展开）
             →  UART_printf()（printf.c）
             →  DMA（通道 7）→ UART 外设 → DIO12 输出
```

`printf_init()`（`printf.c`）在 `app_init.c` 的 `App_Initialize()` 里**无条件调用**，配置引脚 + UART + DMA。

## 三、引脚配置

| 项 | 值 | 位置 |
|----|-----|------|
| 打印口（UART TX） | **DIO12** | pack `printf.c` `UART_TX=12` |
| UART RX | DIO4 | pack `printf.c` `UART_RX=4` |
| 波特率 | 115200 | pack `printf.c` `UART_BAUD_RATE` |
| DMA 通道 | 7 | pack `printf.c` `DMA_UART_TX` |
| 引脚配置 | `DIO_6X_DRIVE \| DIO_WEAK_PULL_UP \| DIO_LPF_ENABLE` | `printf_init()` |

## 四、打印口引脚变更（DIO5 → DIO12）

- 原打印口在 **DIO5**（SDK 默认）。
- 7160test 需要 DIO5 给其他功能（RM 调试输出 `DEBUG_DIO_SECOND`），打印口挪到 **DIO12**。
- 配套改动：
  - **DIO12 原为功能按钮**（短按音量/长按切程序）+ 恢复按钮 → 按键功能已注释（`app.c` 按钮块 `#if 0`），恢复按钮挪到 **DIO7**（`RECOVERY_DIO=7`）。
  - **RM 调试输出** `DEBUG_DIO_SECOND` 用 DIO5（4-8 区间）。

## 五、为什么必须改 SDK pack 里的 printf.c（重要）

`printf.c` 是 **RSL10 SDK 公共文件**（所有工程共用），工程通过 RTE 组件引用它，编译路径由 Eclipse 自动生成在 `Debug/RTE/Utility/subdir.mk`。

**踩坑**：曾把 `printf.c` 复制到工程（`RTE/Utility/printf.c`）改 `UART_TX=12`，但 **Eclipse 重新生成 makefile 时把 subdir.mk 还原成指向 pack 的 printf.c**（UART_TX=5），导致工程副本没生效、打印口一直是 DIO5。

**结论**：要改打印口引脚，必须**直接改 pack 里的 `printf.c`**（`C:\Users\ViewSSS\AppData\Local\Arm\Packs\ONSemiconductor\RSL10\3.9.1182\source\firmware\printf\printf.c`），这样无论 Eclipse 怎么重新生成 makefile，编译用的都是同一份（UART_TX=12）。

**影响**：其他工程（sleep、remote_mic 等）也引用这个 pack 的 printf.c，改动后它们的 `printf_init` 也会把 UART TX 配到 DIO12。但它们大多未开 `DEBUG_UART_ENABLE`（PRINTF 空），且 main 里若有 DIO12 配置会覆盖，实际影响很小。若某工程需要在 DIO5 打印，需单独处理。

## 六、相关文件

| 文件 | 作用 |
|------|------|
| `C:\...\Packs\...\source\firmware\printf\printf.c` | **打印口引脚（UART_TX=12）、波特率、DMA 配置** |
| `include/app.h` | `DEBUG_UART_ENABLE` 总开关；`RECOVERY_DIO=7`；`DEBUG_DIO_SECOND=5` |
| `include/app_trace.h` | `PRINTF` 宏（DEBUG_UART_ENABLE 时 = printf） |
| `app.c` | 按钮块 `#if 0` 注释（DIO12 让给打印口）；`printf_init` 由 `app_init.c` 调用 |
| `code/app_init.c` | `printf_init()` 调用点 |
| `code/app_process.c` | 唤醒后 DIO12 按键重配已注释 |

## 七、验证方法

烧录后串口接 **DIO12**（115200, 8N1），应能看到打印输出。若改用 DIO5 验证（打印口正常），说明 DIO12 引脚/硬件接法有问题，而非打印配置。
