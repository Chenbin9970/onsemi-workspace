# 7100 飞行模式设置（程序 0，开/关）

> **2026-10-22** ｜ 通过抓包解析「程序 0 下飞行模式（文件名 `feixing`）」开关的设置指令。
> 数据源：`feixingoff.txt`（关）、`feixingon.txt`（开），两者均为程序 0 的完整设置会话。
> A7 帧格式见 `docs/7100_A7协议.md` §3。

## 1. 结论速览

两个抓包去掉时间戳与心跳 `88 01` 后，**全部写帧逐条相同，唯一差异是一帧 `A7 04` 的末字节**：

| 动作 | 写序列 |
|------|--------|
| **关** | `A7 05 00 00 00 05 05 00 00 35` → `A7 04 00 00 00 08 00 00 **00**` |
| **开** | `A7 05 00 00 00 05 05 00 00 35` → `A7 04 00 00 00 08 00 00 **06**` |

> ⚠ **这个开关不是布尔量：开 = `0x06`，不是 `0x01`**（自动切换模式是另一套：块 `0x16`、4 字节，
> 见 `docs/7100协议/自动切换模式/7100_自动切换模式设置.md`）。
> 前一条 `A7 05 … 05 05 …` 是选**块 `0x05`**、块内地址 **`0x0035`**。

## 2. 帧结构

```
A7 05 00 00 00 05 05 00 00 35
   └len16=5─┘ └addr=0┘ 05 05 PP 00 35
                        │  │  │  └─ 块内地址 16 位大端 = 0x0035
                        │  │  └──── 程序号（本抓包为 00，见 §5）
                        │  └─────── 块号 0x05
                        └────────── 选块子命令 05

A7 04 00 00 00 08 00 00 <X>
   └len16=4─┘ └addr=0┘ 08 00 00 <X>
                        └── 固定头 ──┘ └ 值：00 = 关 / 06 = 开
```

## 3. 完整设置流程（开/关相同，除 A7 04 值）

每次写后都读回执再发 `82`；`82` 之后等 7100 的 DIO13 沿再走下一步。

| 步骤 | 写帧 | 读回 | 82 |
|------|------|------|:--:|
| ① 预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |
| ② 静音 | `A7 01 00 00 00 25` | `46 00 00` | ✓ |
| ③ 选程序 | `A7 02 00 00 00 12 00` | `46 00 00` | ✓ |
| ④ 预检 | `A7 01 00 03 00 02` | `46 03 00 01 00 1A` | ✓ |
| ⑤ 选块 | `A7 05 00 00 00 05 05 00 00 35` | `46 00 00` | ✓ |
| ⑥ **写开关** | `A7 04 00 00 00 08 00 00 <X>` | `46 00 00` | ✓ |
| ⑦ 确认 | `A7 02 00 00 00 10 00` | `46 00 00` | ✓ |
| ⑧ 等空闲 ×3 | `A7 01 00 03 00 02` | `46 03 00 01 01 1A` / 同上 / `46 03 00 01 00 1A` | ✓×3 |
| ⑨ 解除静音 | `A7 01 00 00 00 26` | `46 00 00` | ✓ |
| ⑩ 选回程序 | `A7 02 00 00 00 12 01` | `46 00 00` | ✓ |
| ⑪ 预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |
| ⑫ 再选程序 | `A7 02 00 00 00 12 01` | `46 00 00` | ✓ |
| ⑬ 预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |
| ⑭ 提交 | `A7 01 00 00 00 0C` | `46 00 00` | ✓ |
| ⑮ 收尾预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |

> 与自动切换模式 / DFBC / 降噪设置流程同构（预检 → 静音 → 选程序 → 写块 → 确认 →
> 解除静音 → 选回 → 提交）。

## 4. 两份抓包的其它差异

| 项 | off | on | 说明 |
|----|-----|----|------|
| 起始心跳 `88 01` | 0.938s 有一条 | 无 | 只是录制起点不同，无意义 |
| `A7 04` 值 | `00` | `06` | **唯一功能差异** |
| 会话后 7100 主动推送 | 3.289s 有 `43 03 00 \| 00 3A 05` | 无 | 见下 |

off 抓包在会话结束约 **317 ms** 后多出一条 7100 主动通知：

```
05 43 03 00 | 00 3A 05      → 寄存器 0x003A 的值变为 0x05
04 82                       → RSL10 读完后还 credit
```

⚠ **不能据此判断它只跟「关」有关**：on 抓包在 2.529s 就结束了，比对应时间点（≈2.85s）还早，
大概率只是**录短了**。需要更长的 on 抓包才能对照。

## 5. 待确认

1. **开为什么是 `0x06`**：不像布尔量。可能是模式索引 / 位掩码 / 某组配置值，需结合读回或
   手册确认；同时也应确认「关」写 `00` 是否正确（还是应该写别的值）。
2. **程序号口径**：本抓包选程序、选块、确认里的程序字段都是 `00`；
   而现有固件与其它抓包（DFBC / 降噪）约定「程序 0 = `01`」（1 基）。
   落地时块 `0x05` 的程序字节与选程序帧大概率应改成 `01`，需上板验证。
3. **块 `0x05` / 地址 `0x0035` 的含义**：现有块号表只记录了 `07/09/0A/0B/10/11`，
   `0x05` 未收录。
4. 寄存器 `0x003A`（`0x43` 通知 payload）是什么属性，未知。
