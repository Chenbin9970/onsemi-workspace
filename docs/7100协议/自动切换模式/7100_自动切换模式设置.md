## 1. 结论速览

两个抓包去掉时间戳与心跳 `88 01` 后，**全部写帧逐条相同，唯一差异是一帧 `A7 07` 的 4 字节值**：

| 动作 | 写序列 |
|------|--------|
| **关** | `A7 05 00 00 00 05 16 00 00 00` → `A7 07 00 00 00 08 00 00 **00 FF FF FF**` |
| **开** | `A7 05 00 00 00 05 16 00 00 00` → `A7 07 00 00 00 08 00 00 **01 00 00 0N**`（N=程序号） |

> **块 `0x16`、块内地址 `0x0000`、4 字节值**
> - 关 = `00 FF FF FF`
> - 开 = `01 00 00 <N>`，**N = 程序号（1 基，支持 1–4）**：
>   - `01 00 00 01` = 在**程序 1** 启用自动切换模式
>   - `01 00 00 02` = 在**程序 2** 启用自动切换模式
>   - `01 00 00 03` / `...04` = 程序 3 / 程序 4（未抓包，按同规律）
>
> **单选语义**：同一时刻只能有一个程序启用自动切换模式；写入新程序号即替换旧值。
>
> 注意：**不是**布尔量。关状态是 `FF FF FF` 填充，不是 `00 00 00`；
> 开状态的末字节是**程序号**，不是固定的 `01`。

## 2. 帧结构

```
A7 05 00 00 00 05 16 00 00 00
   └len16=5─┘ └addr=0┘ 05 16 PP 00 00
                         │  │  │  └─ 块内地址 16 位大端 = 0x0000
                         │  │  └──── 程序号（本抓包为 00，见 §6）
                         │  └─────── 块号 0x16
                         └────────── 选块子命令 05

A7 07 00 00 00 08 00 00 <B0 B1 B2 B3>
   └len16=7─┘ └addr=0┘ 08 00 00 <4 字节设置值>
                        └── 固定头 ──┘

4 字节值：
  01 00 00 <N>   → 在程序 N（1 基，N=1–4）启用自动切换模式（单选）
  00 FF FF FF    → 关闭
```

## 3. 完整设置流程（开/关相同，除 4 字节值）

每次写后都读回执再发 `82`；`82` 之后等 7100 的 DIO13 沿再走下一步。

| 步骤 | 写帧 | 读回 | 82 |
|------|------|------|:--:|
| ① 预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |
| ② 静音 | `A7 01 00 00 00 25` | `46 00 00` | ✓ |
| ③ 选程序 | `A7 02 00 00 00 12 00` | `46 00 00` | ✓ |
| ④ 预检 | `A7 01 00 03 00 02` | `46 03 00 01 00 1A` | ✓ |
| ⑤ 选块 | `A7 05 00 00 00 05 16 00 00 00` | `46 00 00` | ✓ |
| ⑥ **写设置值** | `A7 07 00 00 00 08 00 00 <B0 B1 B2 B3>` | `46 00 00` | ✓ |
| ⑦ 确认 | `A7 02 00 00 00 10 00` | `46 00 00` | ✓ |
| ⑧ 等空闲 ×3 | `A7 01 00 03 00 02` | `46 03 00 01 01 1A` / 同上 / `46 03 00 01 00 1A` | ✓×3 |
| ⑨ 解除静音 | `A7 01 00 00 00 26` | `46 00 00` | ✓ |
| ⑩ 选回程序 | `A7 02 00 00 00 12 01` | `46 00 00` | ✓ |
| ⑪ 预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |
| ⑫ 再选程序 | `A7 02 00 00 00 12 01` | `46 00 00` | ✓ |
| ⑬ 预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |
| ⑭ 提交 | `A7 01 00 00 00 0C` | `46 00 00` | ✓ |
| ⑮ 收尾预检 | `A7 01 00 03 00 02` | `46 03 00 00 00 1A` | ✓ |

> 与飞行模式 / DFBC / 降噪设置流程同构（预检 → 静音 → 选程序 → 写块 → 确认 →
> 解除静音 → 选回 → 提交）。

## 4. 已观测到的值

| 抓包 | 4 字节值 | 含义 |
|------|----------|------|
| `program0autochanggeoff.txt` | `00 FF FF FF` | 自动切换模式：关 |
| `program0autochanggeon.txt` | `01 00 00 01` | 在**程序 1** 启用 |
| `2026-10-22_15-16-57.txt` | `01 00 00 01` | 在**程序 1** 启用（与上一行完全一致） |
| `2026-10-22_16-21-05.txt` | `01 00 00 02` | 在**程序 2** 启用 |

后两份是整包保存抓包（见 §5），块 `0x16` 的写入与开关抓包逐字节同构。

**值语义（已确认）**：

- `01 00 00 <N>` 的末字节 = **程序号（1 基）**，表示在程序 N 启用自动切换模式；
  支持程序 1–4（3/4 未抓包，按同规律外推）。
- **单选**：同一时刻只有一个程序能启用；写程序 2 会覆盖程序 1，寄存器只有一份。
- `00 FF FF FF` = 关闭。
- 前两字节 `00 00` 的含义待确认。

## 5. 与飞行模式、整包保存抓包的关系

- **飞行模式**是另一套指令：块 `0x05`、块内地址 `0x0035`、`A7 04` 单字节（`00` 关 / `06` 开），
  见 `docs/7100协议/飞行模式/7100_飞行模式设置.md`。**与块 `0x16` 无关。**
- `2026-10-22_15-16-57.txt` 与 `2026-10-22_16-21-05.txt` 是**同一套操作的两次录制**：
  1. 全量写入程序 1（WDRC 1012B + 97B、DFBC、块 `0x0B`、块 `0x10` 445B）；
  2. 程序 0 会话内，**关闭飞行模式**（块 `0x05`/`0x0035` = `00`）；
  3. 紧接着写**自动切换模式**（块 `0x16`）。
- 两份抓包的大块内容逐字节相同（sha1 一致），唯一功能差异就是块 `0x16` 的末字节：
  - `15-16-57`：`01 00 00 01` → 在**程序 1** 启用
  - `16-21-05`：`01 00 00 02` → 在**程序 2** 启用
- 因此：自动切换模式与飞行模式可以**在同一次保存里连续写入**，写完后只需一次
  `10 00` 确认 + 一次 `0C` 提交。

## 6. 待确认：程序号口径

本抓包里程序号字段是 `00`：

- 选程序 `A7 02 00 00 00 12 **00**`
- 选块 `A7 05 00 00 00 05 16 **00** 00 00`
- 确认 `A7 02 00 00 00 10 **00**`

而**现有固件与其它抓包的约定是「程序 0 = `01`」**（1 基）：

- `7100_DFBC设置.md`：`A7 02 00 00 00 12 01` = 程序 0，块 `0A 01`
- `7100_降噪档位读取.md` §97：`12 01`→程序0、`12 02`→程序1、`12 03`→程序2、`12 04`→程序3
- 本机 `dsp_7100_cmd.c` 的 `s_sess_prog` 也是 1–4

**目前证据倾向**：`00` 是一个独立的「全局/基础槽」，程序开关类设置（飞行模式、
自动切换模式）都写在槽 `00`，而真实程序 1–4 用 `01–04`。飞行模式、自动切换模式
以及两份整包抓包**全部使用 `00`**，这不是单次笔误。

上板落地时先按 `00` 原样发；若写不进去再改 `01` 试。**两种都要看读回确认，暂不当作已定论。**
