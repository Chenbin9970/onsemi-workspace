## 1. 结论速览

- **AGCO 参数写入 `A7 F4` + `A7 61`，不写 BD**（与 EQ 相反）
- **F4 = 每通道 AGCO 参数块**：`[头 ~82B][16 × 51B 通道段][尾 ~120B]`
- AGCO 0→1 使 F4 **16 处变化**（每通道段 1 字节，各 -1）

## 2. 功能分块对照

| 调整 | 写入块 |
|------|--------|
| EQ | `A7 BD`（大幅 + `A7 F4`） |
| **AGCO** | **`A7 F4` + `A7 61`** |
| DFBC | `A7 04` |
| 降噪 | `A7 27` |

## 4. F4 结构

```
[头 ~82B（含增益表）][16 × 51B 通道段][尾 ~120B]
```

- 通道段起始约 idx 82, 133, 184, ...（间隔 51）
- 每段含 AGCO（及其他 DSP）参数
- AGCO 多参数（Gain/Threshold/Attack/Release）改动会牵动段内多处

```
（无 A7 BD）
```
