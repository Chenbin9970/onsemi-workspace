## 4. 差异 ②：`A7 07` 帧

两帧都是 12 字节，前 8 字节相同，**只有最后 4 字节不同**：

| | 整帧 |
|---|---|
| set31 | `04 A7 07 00 00 00 08 00 00` **`1F 06 4F C9`** |
| set40 | `04 A7 07 00 00 00 08 00 00` **`28 07 CE 79`** |

- 首字节 `1F` = 十进制 **31**，`28` = 十进制 **40**，与设置的 AGCO 档位一致
- 后 3 字节 `06 4F C9` → `07 CE 79` 的含义未知
