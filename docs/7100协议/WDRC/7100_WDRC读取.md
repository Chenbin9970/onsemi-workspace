# 7100 WDRC 读取（程序0，LowLevel / HighLevel Gain）

> **2026-09-04** ｜ 通过读回抓包定位 WDRC LowLevel/HighLevelGain 字段。
> 数据源：`wdrcreadp0channel2lowlevel20/25/27/28/30`、`channel5lowlevel30`、`channel10lowlevel30`（多通道设定读回）。
> 各抓包通道设定（用户确认）：
> - channel2lowlevel30: ch2=30, ch5=20, ch10=20
> - channel5lowlevel30: ch2=30, ch5=30, ch10=20
> - channel10lowlevel30: ch2=30, ch5=20, ch10=30

## 1. 结论速览

**WDRC LowLevel/HighLevelGain 是 7bit 值**（范围 -30~60），每通道间隔 **147 bit**，嵌在 `0x0177` 块：

```
LowLevelGain  @ bit = 446 + (N-2)×147
HighLevelGain @ bit = LowLevelGain位 + 15
（7bit 值，若 ≥64 则 -128 = 负值补码）
```

每通道 147 bit 非字节对齐（147 mod 8=3），故字段跨两字节、各通道字节内位偏移不同。

### 设置 / 读取速查

| | LowLevelGain (ch N) | HighLevelGain (ch N) |
|---|---|---|
| **读取命令** | `A7 01 00 77 01 38` → 0x0177 块 | 同左 |
| **读取位置** | bit `446+(N-2)×147`（7bit） | bit LowLevel位+15（7bit） |
| **设置参数号** | `0x15 + 0x11×(N−1)` | `0x17 + 0x11×(N−1)` |
| **设置写** | `A7 05 <参数号>` → `A7 04 08 00 00 <值>` | 同左（值有符号） |
| **值范围** | -30 ~ 60 | -30 ~ 60 |

> 设置写法详见 `7100_WDRC设置.md`。

## 2. 逐通道字段位置（已验证）

| 通道 | 值跨字节 | 解码公式 | 验证 |
|:---:|------|------|------|
| **ch2** | byte55 bit1:0 + byte56 bit7:3 | `(byte55&0x03)<<5 \| (byte56>>3)` | 20→`A6` 30→`F6` ✓ |
| **ch5** | byte110 bit0 + byte111 bit7:2 | `(byte110&0x01)<<6 \| (byte111>>2)` | 20→`53` 30→`7B` ✓ |
| **ch10** | byte202 bit1:0 + byte203 bit7:3 | `(byte202&0x03)<<5 \| (byte203>>3)` | 20→`A6` 30→`F6` ✓ |

验证 ch2=20：byte55=`90`(低2位=00) + byte56=`A6`(>>3=20) → 值=20 ✓

> **值<32 时高位字节的 1-2 bit 恒 0**，只有低 5 位所在字节变（所以最初只看到 byte56 变，误以为是单字节 `(值<<3)|6`）。
> **负值**（-30~60 范围）：7bit 补码（-30 = `1100010`）。

## 3. 差异定位过程

- ch2 变 → byte56 变（低5位）
- ch5 变 → byte111 变
- ch10 变 → byte203 变
- 0x30 块 bytes14-15 也随各通道变（校验/派生，待定）

> 0x0177 每程序读一次；0x30 每程序读一次。

## 4. 通道排列规律（关键发现）

**每个通道 lowlevel 是 7bit 值，通道间间隔 147 bit**（非字节对齐，147 mod 8 = 3，故各通道字段在字节内位偏移不同）：

```
chN 的 7bit 值 @ bit = 446 + (N-2)×147   （0x0177 响应内，从 05 46 77 01 起）
```

验证（程序0 全 16 通道，ch2lowlevel30 抓包）：

> 3 个已知通道（30/20/20）全部命中，其余默认 15（用户确认 ✓）。

## 5. HighLevelGain（已验证）

**HighLevelGain 字段 = 每通道 LowLevel 位 + 15 bit**（同样 7bit）：

```
HighLevelGain @ bit = 446 + (N-2)×147 + 15
```

定位依据：ch5 HighLevel 设 10 → 在 lowlevel+15 位精确命中（其余偏移不匹配）。

程序0 全通道（ch2lowlevel30 抓包）：

| 通道 | LL | HL | | 通道 | LL | HL |
|:---:|:---:|:---:|---|:---:|:---:|:---:|
| ch1 | 15 | -16 | | ch9 | 15 | -7 |
| ch2 | 30 | -7 ✓ | | ch10 | 20 | -9 |
| ch3 | 15 | -3 | | ch11 | 15 | -11 |
| ch4 | 15 | -1 | | ch12 | 15 | -14 |
| ch5 | 20 | 10 ✓ | | ch13 | 15 | -16 |
| ch6 | 15 | -1 | | ch14 | 15 | -19 |
| ch7 | 15 | -3 | | ch15 | 15 | -19 |
| ch8 | 15 | -5 | | ch16 | 15 | -19 |

> ch2=-7、ch5=10 命中之前设置值 ✓；各程序 highlevel 为跨通道增益曲线（用户确认完全正确）。
> 程序1/2/3 highlevel 曲线见抓包解码（ch2lowlevel30 抓包可复算）。

## 6. 读取公式（最终）

```
LowLevelGain  @ bit = 446 + (N-2)×147          （7bit）
HighLevelGain @ bit = LowLevel位 + 15           （7bit）
值解释: 7bit，若 ≥64 则 -128（-30~60 范围，负值补码）
```

所有程序通用（已验证程序0/1/2/3）。
