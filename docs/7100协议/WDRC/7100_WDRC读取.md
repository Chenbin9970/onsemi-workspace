# 7100 WDRC 读取（0x0177 块字段定位）

> **2026-09-04 创建，2026-09-10 补充 UpperThreshold / OutputLimit** ｜ 通过读回抓包定位 WDRC 字段。
> 数据源：`wdrcreadp0channel2lowlevel20/25/27/28/30`、`channel5lowlevel30`、`channel10lowlevel30`（多通道设定读回）。
> 各抓包通道设定（用户确认）：
> - channel2lowlevel30: ch2=30, ch5=20, ch10=20
> - channel5lowlevel30: ch2=30, ch5=30, ch10=20
> - channel10lowlevel30: ch2=30, ch5=20, ch10=30

## 1. 结论速览

WDRC 各参数以 **147 bit 为一个通道单元**，顺序排列在 `0x0177` 块内（与 7111 地址表 0x15→0x16→0x17→0x18→0x19 一致）：

```
ch N 的参数位 = 446 + (N-2)×147 + 单元内偏移
```

| 参数 | 7111 地址 | 单元内偏移 | 位宽 | 编码 | 程序0 实测 |
|---|---|---|---|---|---|
| LowLevelGain | 0x15 | **0** | 7bit | 无符号 | 15 / 30 / 20 |
| UpperThreshold | 0x16 | **7** | 7bit | 无符号 | **110**（全通道） |
| HighLevelGain | 0x17 | **14** | 8bit | **有符号** | -16 / -7 / 10 |
| OutputLimit | 0x18 | **22** | 8bit | **有符号** | **-6**（全通道） |
| (WB AGCO Gain) | 0x19 | 30 | 8bit? | 待确认 | 平滑曲线 |

- 每通道 147 bit 非字节对齐（147 mod 8 = 3），故字段跨两字节、各通道字节内位偏移不同。
- **ch2 的 LowLevelGain = bit 446**（沿用本文原坐标系，与 `wdrcreadp0channel2*` 抓包一致）。
- 有符号字段：读到值 ≥ 2^(位宽-1) 则减去 2^位宽（如 OL 的 `0xFA` → -6）。无符号字段（LL / UT）不做补码转换。

### 设置 / 读取速查

| | LowLevel (0x15) | UpperTh (0x16) | HighLevel (0x17) | OutputLimit (0x18) |
|---|---|---|---|---|
| **读取命令** | `A7 01 00 77 01 38` → 0x0177 块 | 同左 | 同左 | 同左 |
| **读取位置** | bit `446+(N-2)×147` +0 | +7 | +14 | +22 |
| **位宽 / 编码** | 7bit 无符号 | 7bit 无符号 | 8bit 有符号 | 8bit 有符号 |
| **设置参数号** | `0x15 + 0x11×(N−1)` | `0x16 + 0x11×(N−1)` | `0x17 + 0x11×(N−1)` | `0x18 + 0x11×(N−1)` |
| **设置写** | `A7 05 <参数号>` → `A7 04 08 00 00 <值>` | 同左 | 同左 | 同左 |

> 设置写法详见 `7100_WDRC设置.md`。
> ⚠️ 本文旧版写的 `HighLevelGain @ LowLevel位 + 15（7bit）` 已修正为 **+14（8bit 有符号）**，见 §9。

## 2. 逐通道字段位置（已验证）

| 通道 | 值跨字节 | 解码公式 | 验证 |
|:---:|------|------|------|
| **ch2** | byte55 bit1:0 + byte56 bit7:3 | `(byte55&0x03)<<5 \| (byte56>>3)` | 20→`A6` 30→`F6` ✓ |
| **ch5** | byte110 bit0 + byte111 bit7:2 | `(byte110&0x01)<<6 \| (byte111>>2)` | 20→`53` 30→`7B` ✓ |
| **ch10** | byte202 bit1:0 + byte203 bit7:3 | `(byte202&0x03)<<5 \| (byte203>>3)` | 20→`A6` 30→`F6` ✓ |

验证 ch2=20：byte55=`90`(低2位=00) + byte56=`A6`(>>3=20) → 值=20 ✓

> **值<32 时高位字节的 1-2 bit 恒 0**，只有低 5 位所在字节变（所以最初只看到 byte56 变，误以为是单字节 `(值<<3)|6`）。
> **负值**（-30~60 范围）：7bit 补码（-30 = `1100010`）。

## 3. 差异定位过程

- ch5 变 → byte111 变
- ch10 变 → byte203 变

> 0x0177 每程序读一次；0x30 每程序读一次。

## 5. HighLevelGain（已验证）

**HighLevelGain 字段 = 每通道 LowLevel 位 + 14 bit，8bit 有符号**（占 bits 14~21）：

```
HighLevelGain @ bit = 446 + (N-2)×147 + 14
值解释: 8bit 有符号，若 ≥128 则 -256
```

定位依据：ch5 HighLevel 设 10 → 在 lowlevel+14 位精确命中（其余偏移不匹配）。

> 本文旧版记作 `+15 / 7bit`：数值上两种读法结果相同（因最低位那侧符号位重复，诸通道实测 `bit14 == bit15`），
> 但 `+15` 会漏掉 bit14。UT=110 的实测确认 bit14 不属于 UT（见 §9），故 **bit14 归 HL**，HL 起点为 +14。

| ch3 | 15 | -3 | | ch11 | 15 | -11 |

## 6. 读取公式（最终）

通道单元起点 = `446 + (N-2)×147`，各字段相对起点偏移：

```
LowLevelGain      @ +0    7bit  无符号
UpperThreshold    @ +7    7bit  无符号
HighLevelGain     @ +14   8bit  有符号
OutputLimit       @ +22   8bit  有符号
(WB AGCO Gain?)   @ +30   8bit? 待确认
```

有符号解释：读到值 ≥ 2^(位宽-1) 则减 2^位宽。无符号（LL / UT）不转换。

所有程序通用（已验证程序0/1/2/3）。

## 9. UpperThreshold / OutputLimit 定位（2026-09-10 补充）

在 `0x0177` 块内改用**按通道单元周期性扫描**定位，而非逐字节比对。

### 坐标系确认

先用已确认的 LowLevel 图案（ch2=30、ch5=20、ch10=20、其余 15）暴搜位原点，
只有 **MSB-first、payload 含 `05` 头**时 ch2 命中 bit 446，与 §4 一致。

### 扫描方法

对每个候选偏移 d（0~146），检查 16 个通道 × 全部程序在该处的取值：

| 找到的偏移 | 读数 | 判定 |
|---|---|---|
| d = 7 | 全通道 = **110**（无符号 7bit） | UpperThreshold |
| d = 22 | 全通道 = **-6**（有符号 8bit） | OutputLimit |
| d = 30 | 跨通道平滑曲线（-23 ~ -20） | 疑似 WB AGCO Gain |

- OutputLimit 在 7bit 读法下唯一命中 d=23；其左侧一位恒为 1，即符号位 → 实为 **8bit @ d=22**（`0xFA` = -6）。

### UT=110 钉死了字段宽度

- UT 只需 7 位即可表示 110（`1101110`），**bit14 未被 UT 使用**
- 而 bit14 在所有抓包中恒等于 HL 的符号位（P1 ch1 HL=-16 → bit14=1；P2 ch1 HL=+1 → bit14=0）
- ⇒ **bit14 属于 HL**，HL 是 8bit 有符号 @ +14，下一字段（OL）自然从 +22 起

### 字节级取法

147 mod 8 = 3，各通道位偏移不同，需按位取：

```c
bit = 446 + (N - 2) * 147 + 22;     /* N = 1..16 对应 ch1..ch16 */
bi  = bit >> 3;
off = bit & 7;
v   = (off == 0) ? p[bi]
    : ((p[bi] & ((1 << (8 - off)) - 1)) << off) | (p[bi + 1] >> (8 - off));
if (v >= 128) v -= 256;             /* OutputLimit: 0xFA -> -6 */
```

程序0 ch1/ch2/ch9 实测（`p` = **完整响应帧**，即从地址字节 `05` 起、含 `46 77 01` 头；与 `bit` 同坐标系）：

| 通道 | bit | 字节 | 编码字节 | 值 |
|---|---|---|---|---|
| ch1 | 321 | 40,41 | `7D 74` | -6 |
| ch2 | 468 | 58,59 | `9F AE` | -6 |
| ch9 | 1497 | 187,188 | `FD 73` | -6 |

### 验证覆盖

7 个 `wdrcreadp0*.csv` × 4 程序 × 16 通道 = **448 个通道值**：
UpperThreshold 全为 110、OutputLimit 全为 -6，**0 处不符**。

> 注意：UT 是**无符号**读（按 7bit 有符号读会得到 -18 而误判），OL 是**有符号** 8bit。
