> 数据源：`P0wdrcchannel1set27/28`（实为 ch2 LowLevelGain）、`P0wdrchighlevergainchannel1set-6/-7`（实为 ch2 HighLevelGain）、`P0wdrclowlevergainchannel5/10set20`、`P0wdrchighlevergainchannel5set10`。

## 1. 结论速览

WDRC 增益用 **`A7 04` 直接写值**，参数由前面 `A7 05` 准备命令选择：

```
A7 05 00 00 00 05 07 01 00 <参数号>   ← 选通道+参数
A7 04 00 00 00 08 00 00 <值>          ← 写值
```

**参数号公式（已验证）**：
```
LowLevelGain  (ch N) = 0x15 + 0x11×(N−1)
HighLevelGain (ch N) = LowLevelGain + 2
```

### 设置 / 读取速查

| | LowLevelGain (ch N) | HighLevelGain (ch N) |
|---|---|---|
| **设置参数号** | `0x15 + 0x11×(N−1)` | `0x17 + 0x11×(N−1)` |
| **设置写** | `A7 05 <参数号>` → `A7 04 08 00 00 <值>` | 同左（值有符号） |
| **读取命令** | `A7 01 00 77 01 38` → 0x0177 块 | 同左 |
| **读取位置** | bit `446+(N-2)×147`（7bit） | bit LowLevel位+15（7bit） |
| **值编码** | 无符号 | 有符号 |
| **值范围** | -30 ~ 60 | -30 ~ 60 |

> 读取解码详见 `7100_WDRC读取.md`。

| 参数 | 编码 | 示例 |

| LowLevelGain | 无符号直接存 | 20→`14`，27→`1B`，28→`1C` |

## 4. 完整写流程

```
预读(0x03/0x02) → 静音0x25 → A7 02 12 01(选程序0)
→ A7 05 00 00 00 05 07 01 00 <参数号>
→ A7 04 00 00 00 08 00 00 <值>
→ A7 02 10 01 → 解除静音0x26 → 确认
```
