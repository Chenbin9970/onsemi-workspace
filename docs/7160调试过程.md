# 7160 调试过程总览（子模块文档目录）

> **2026-08-27**：本项目是 7160test 工程（`peripheral_server_sleep7160test`），从 `peripheral_server_sleep` 复制，用于开发 **Ezairo 7160SL 模组**（7100 DSP + RSL10 BLE）。
>
> 本文件是调试过程的**总览和目录**，各子模块的细节见对应文档。

## 一、项目背景

- 通讯对象从 **BS300 DSP → 7100**，BS300 功能已整体关闭（`app.h` 的 `BS300_ENABLE` 宏，默认注释）。
- I2C 驱动从软件 bit-bang 改为 **RSL10 硬件 I2C0**（中断驱动），目标速度 ~400kHz。
- 打印口用 **UART**（DIO12，115200）。

## 四、当前 IO 分配（2026-08-28）

> **2026-08-28 更新**：加了 PCM slave 输出（参照 `remote_mic_rx_rawtest1`）。7100 做时钟主机，
> RSL10 从机把解码音频（ASRC 16k→12k）移位输出到 7100。DIO2/3/4/14 让给 PCM；
> 电池 ADC（DIO3）停用，LED（DIO6）删除。
> 备用 **OD 输出模式**（`OD_DIO12_OUTPUT` 宏）：DIO12 做 OD_P，关打印、关 PCM（参照 `peripheral_server_sleep`）。

| DIO | 用途 |
|-----|------|
| 0 / 1 | I2C SCL / SDA（7100 通讯） |
| 2 | **PCM BCLK 输入**（7100 提供 384 kHz） |
| 3 | **PCM FS 输入**（7100 提供 12 kHz；原电池 ADC，已停用 `BAT_ADC_ENABLE`） |
| 4 | **PCM SERI 输入**（从机不回传，未用；原 UART RX） |
| 5 | RM 调试输出 |
| 6 | **UART RX**（原 LED，LED 已删；pack printf.c `UART_RX` 改到 DIO6） |
| 7 | 恢复按钮（接地暂停重烧） |
| 9 / 10 / 11 | 空闲 |
| 12 | **UART 打印口（TX）**；`OD_DIO12_OUTPUT` 打开时改作 **OD_P 输出**（关打印） |
| 13 / 15 | JTAG（TRST/TDI；DIO14 运行时关闭 JTAG data 释放给 PCM） |
| 14 | **PCM SERO 输出**（原 JTAG，`App_Initialize` 运行时关 JTAG 后作 SERO） |

## 五、关键调试结论（速查）

1. **I2C 地址**：7100 总线地址字节 = `0x04`（7-bit 0x02），`Sys_I2C_StartWrite` 内部左移，传 0x02。
2. **I2C 必须中断驱动**：纯轮询在地址 ACK 后卡死（外设每字节需 CPU 中断响应）。
3. **ACK 极性**：STATUS bit0=0 表示 ACK（`I2C_HAS_ACK=0`）。
4. **打印口必须改 pack 的 printf.c**：改工程副本会被 Eclipse 重新生成 makefile 还原。
5. **引脚上拉用强上拉**：`DIO_STRONG_PULL_UP`，否则总线挂死。
6. **OD 输出占 DIO0/1**：已关闭（`AUDIO_CONFIG` 去 `OD_ENABLE`），让给 I2C。
7. **PCM slave 输出**：7100 做时钟主机（BCLK=DIO2 384k / FS=DIO3 12k），RSL10 从机 SERO=DIO14；`ASRC DEC_MODE2` 16k→12k；`pcm_tx_buf` 双缓冲（ch4 填 / ch5 流），数据在 word1 右声道；`ASRC_DITHER` 未移植（有静音蚊蚊再处理）。
8. **电池 ADC 停用**：DIO3 让给 PCM FS，`BAT_ADC_ENABLE` 默认注释，`read_battery_raw()` 固定返回 100%。
9. **OD 输出模式**（`OD_DIO12_OUTPUT`）：DIO12 做 OD_P（单端），`OUTPUT_INTERFACE=OUTPUT_DISABLED` 关打印、PCM 分支整体 `#else`；ASRC `DEC_MODE1` + `<<29`、采样钟 DIO7；`BufferOut→OD_DATA`（CIRC）。见 `docs/pcm/7160test_pcm_output.md` §6。
