二、机身功能定义
────────────────────────────────

运行模式：

  模式              功耗     说明
  ────────────────  ───────  ──────────────────
  BLE 低功耗从机    600μA    BLE peripheral
  RM RX             900μA    接收 RM 音频流

- 机身 = BLE 从机，充电盒 = BLE 主机

────────────────────────────────

  芯片                功能
  ──────────────────  ──────────────────────────

四、工作流程
────────────────────────────────

无音频（待机）：
  - RSL10 处于 BLE 主机模式，同时连接两个机身
  - 机身处于 BLE 低功耗从机模式（600μA）
  - RSL10 维持 BLE 连接，监听 AD6976 DMIC

有音频（推流）：
  1. AD6976 收到手机音频 → DMIC 输入 RSL10
  2. RSL10 检测到音频 → BLE 发 RM_ONOFF=1 → 机身切 RM RX（900μA）
  3. RSL10 自身切 RM TX 模式，开始广播推流
  4. 两个机身同时接收音频

音频结束：
  1. RSL10 检测到静音 → 停止 RM TX，切回 BLE 模式
  2. RSL10 发 BLE 指令 RM_ONOFF=0 → 机身切回 BLE 低功耗模式

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

五、充电盒方案设计
────────────────────────────────

1. 音频检测方案
   AD6976 无状态输出脚，由 RSL10 监听 DMIC，用 EMA
   能量阈值判断有无音频。方案已在上位机验证。

2. BLE 模式切换协议
   复用现有 Custom Service 的 RM_ONOFF 特征值：

    指令            值       含义
   ──────────────  ───────  ────────────────
   RM_ONOFF write  1        机身切 RM RX
   RM_ONOFF write  0        机身切 BLE 低功耗

   时序：
   - RSL10 发 RM_ONOFF=1 → 等 N ms → 自身切 RM TX 推流
   - 音频结束 → 停 RM TX → 发 RM_ONOFF=0

3. RFX2401C RF 路径控制

   场景            TXEN(IO11)  RXEN(IO10)  说明
   ──────────────  ──────────  ──────────  ──────────────────
   BLE 扫描/连接   0           1           RX 通路，LNA 提升距离
   RM TX 推流      1           0           TX 通路，PA 提升距离
   空闲/休眠       0           0           省电

   切换时序：先关当前通路 → 再开目标通路，避免同时 HIGH

4. 充电盒状态机

   INIT ──→ SCANNING ──→ CONNECTING ──→ CONNECTED ──→ STREAMING
                                      ↑                │
                                      │   音频结束      │
                                      └────────────────┘
                    任意阶段断连 → RECOVER → 重新扫描

   状态转换表：

   当前状态    事件              下一状态    动作
   ──────────  ────────────────  ──────────  ────────────────────
   INIT        BLE 就绪          SCANNING    启动扫描
   SCANNING    MAC 匹配到机身    CONNECTING  停止扫描，发起连接
   CONNECTING  两机身均连上      CONNECTED   保持 BLE 连接
   CONNECTING  超时未连上        SCANNING    重新扫描
   CONNECTED   检测到音频        STREAMING   发RM_ONOFF=1→切TX→RM_Enable
   CONNECTED   机身断连          SCANNING    重新扫描
   STREAMING   音频结束          CONNECTED   停RM→切RX→发RM_ONOFF=0
   STREAMING   机身断连          SCANNING    停RM，重新扫描

5. 确认项

   Q1 音频检测      RSL10 DMIC 能量检测
   Q2 音频接口      DMIC
   Q3 模式切换指令  复用 Custom Service RM_ONOFF
   Q4 双机身分配    RM TX 广播，两机身同时收同一路
   Q5 功耗要求      无特殊要求
   Q6 IO11 电压     先不管

六、测试数据分析与推论
────────────────────────────────

关键发现：

  1. BLE 扫描距离是瓶颈，RM TX 余量充足
     BLE 扫描（机身→充电盒） 5-11m
     RM TX （充电盒→机身）  20-56m
     → BLE 和 RM 覆盖范围严重不对称

  2. PA 的收益
               无PA        有PA          提升
     ────────  ──────────  ────────────  ──────────
     BLE 扫描  5-8m        8-11m         +3m
     RM TX     仅开发板    全部可穿墙    质的飞跃
             可穿墙

  3. 机身天线差异巨大
                 扫描距离    TX 距离
     ──────────  ──────────  ──────────
     1654 开发板  20m         56m
     1654 机身    5m          20m
     → 同一芯片，开发板是机身的 3-4 倍距离

推论：

  推论A：机身必须支持 RM 超时自动切回 BLE
    原因：BLE 范围 5-11m，RM TX 范围 20-56m
    场景：用户在 BLE 边缘走入 → 音频结束 → 充电盒发
          RM_ONOFF=0 → 机身Ble已断 → 收不到 → 机身
          永远停在 RM RX（900μA 跑空）
    方案：机身 RM RX 模式 N 秒无 RM 信号 → 自动切 BLE

  推论B：充电盒必须带 PA
    无PA 只能在理想条件覆盖 20-22m 且不能穿墙
    充电盒使用场景必然需要穿墙，PA 是必须的

  推论C：BLE 连接保持是系统薄弱环节
    - 连接建立后尽量保持，断连才重扫
    - BLE 参数合理配置
    - 机身 BLE 广播功率尽量拉满

机身端需要新增：

  功能                    说明
  ──────────────────────  ──────────────────────────
  RM 超时自动切回 BLE     机身 RM RX N秒无信号→切BLE

充电盒 TX 端需要新增/调整：

  功能                    说明
  ──────────────────────  ──────────────────────────
  恢复 BLE 连接逻辑       扫到→连接→保持连接
  音频检测触发 RM_ONOFF   检测到音频→发RM_ONOFF=1
  音频停止触发回切        停RM TX→发RM_ONOFF=0
  断连处理                任一机身断连→重新扫描

功耗估算：

  状态            RSL10 BLE  RFX2401C  合计
  ──────────────  ─────────  ────────  ────
  待机(BLE连接)   ~12mA      0         ~12mA
  推流(RM TX)     ~12mA      +60mA     ~72mA

  RFX2401C TX 模式实测多 60mA，仅推流期间发生。

风险点：

  风险                   等级  应对
  ─────────────────────  ────  ──────────────────────────
  BLE/RM 覆盖不对称      中    机身 RM 超时自动回落 BLE
  S2 空板 IO11 2.7V      低    实测不影响功能，后续加下拉
  双机身同时连接稳定性   低    PEER_COUNT 机制已验证
  AD6976 DMIC 静音噪声   中    需调阈值，上线前实测
