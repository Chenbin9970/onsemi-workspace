  机身 & 充电盒 配合方案对比
  2026-08-05
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

前提条件（来自实测数据）
────────────────────────────────

  参数                    值           说明
  ──────────────────────  ───────────  ──────────────────
  BLE 连接距离（机身）    5-11m        机身天线弱，是瓶颈
  RM TX 距离（充电盒）    20-56m       2-4 倍于 BLE
  机身 BLE 从机功耗       600μA        持续广播 + 连接
  机身 RM RX 功耗         900μA        持续监听（无信号时）
  机身 RM RX 推流功耗     ~1mA         接收并输出音频时

充电盒功耗（实测）
────────────────────────────────

  RSL10 BLE 主机连接机身    200μA
  AD6976 连接手机（待机）   ~500μA
  AD6976 播放音频           6mA
  RFX2401C PA TX 使能       60mA

  充电盒各状态总功耗：
    状态                    RSL10   AD6976   PA      合计
    ──────────────────────  ──────  ───────  ───────  ─────
    机身拿出，BLE 待机     200μA   500μA    0        ~0.7mA
    音频推流（RM TX）      200μA   6mA      60mA     ~66mA

  充电盒续航（700mAh 电池）：
    状态                    续航
    ──────────────────────  ───────────
    BLE 待机                ~1000h（42 天）
    持续推流                ~10.5h

  充电盒的核心功能：
  1. 充电：为两个机身充电（座舱大电池供电）
  2. 控制：RSL10 作为主控芯片，管理整个系统

  工作逻辑：
  - 机身放入充电盒 → 充电 + RSL10 待机，AD6976 关闭
  - 机身从充电盒拿出 → RSL10 检测 → 开启 AD6976 → BLE 扫描/连接
  - AD6976 仅在机身拿出后开启
  - 充电盒 BLE 待机仅 0.7mA，续航 42 天
  - 充电盒功耗完全不是瓶颈，方案选择以机身 15mAh 的
    功耗和连接可靠性为优先

核心矛盾：RM 链路覆盖范围 2-4 倍于 BLE 链路。
BLE 指令在覆盖边缘不可靠，机身不能单纯依赖 BLE 指令做模式切换。

方案一：BLE 指令型
────────────────────────────────

  机身默认：BLE 从机（600μA），充电盒 BLE 常连
  进入 RM：充电盒检测到音频 → BLE 发 RM_ONOFF=1 → 机身切 RM RX
  退出 RM：音频停 → BLE 发 RM_ONOFF=0 → 机身切回 BLE
  安全兜底：机身 RM RX 模式 30s 无 RM 信号 → 自动回 BLE

  ┌──────────┐   BLE(常连)   ┌──────────┐
  │  充电盒   │◄─────────────►│   机身   │
  │  0.7mA   │  RM_ONOFF指令  │ BLE 600μA│
  └──────────┘               └──────────┘
       │ 检测到音频
       │ BLE:RM_ON=1
  ┌──────────┐               ┌──────────┐
  │  充电盒   │               │   机身   │
  │  切RM TX │═══RM TX 广播══→│ 切RM RX  │
  │  66mA    │               │  900μA   │
  └──────────┘               └──────────┘
       │ 音频停
       │ BLE:RM_ON=0
  ┌──────────┐               ┌──────────┐
  │  充电盒   │               │   机身   │
  │  切BLE   │               │ 切BLE   │
  │  0.7mA   │               │  600μA   │
  └──────────┘               └──────────┘

  功耗估算（15mAh 机身 / 700mAh 充电盒）：

    使用模式              机身功耗  充电盒功耗  机身续航  充电盒续航
    ────────────────────  ────────  ──────────  ────────  ──────────
    BLE 待机              600μA     0.7mA       ~25h      ~1000h
    RM 推流               900μA     66mA        ~17h      ~10.5h
    典型日（30% 推流）    690μA     ~20mA       ~22h      ~35h

  优点：
  - BLE 指令控制，切换快（<100ms），充电盒明确知道机身状态
  - BLE 常连可传音量、电量、校准参数
  - 可渐进优化：长 BLE interval 可降待机至 ~500μA（续航 30h）

  缺点：
  - 覆盖受限于 BLE 距离（5-11m）
  - 超出 BLE 范围后指令失效，依赖机身 RM 超时兜底

  可实现性：★★★★★
  与现有 TX 工程最接近，改动量最小。

════════════════════════════════════════════════════

方案二：RM RX 常驻型
────────────────────────────────

  机身默认：RM RX（900μA），不维持 BLE 连接
  充电盒：检测到音频 → 直接切 RM TX 广播
  机身：检测到 RM 信号 → 音频输出，信号消失 → 继续 RM RX 等待
  BLE：仅在需要时按需建立（配对、调音量）
  前提：BLE 模式下无法检测 RM 载波，必须 RM RX

  ┌──────────┐               ┌──────────┐
  │  充电盒   │   无BLE连接    │   机身   │
  │  0.7mA   │               │  RM RX   │
  └──────────┘               │  常驻监听 │
       │                      │  900μA   │
  检测到音频                   └──────────┘
       │
  ┌──────────┐               ┌──────────┐
  │  充电盒   │               │   机身   │
  │  切RM TX │═══RM TX 广播══→│ 检测到RM │
  │  66mA    │               │ 音频输出 │
  └──────────┘               │  ~1mA    │
                              └──────────┘
  音频停：
  ┌──────────┐  RM信号消失    ┌──────────┐
  │  充电盒   │               │   机身   │
  │  切BLE   │               │ 继续RM RX│
  │  0.7mA   │               │  等待信号 │
  └──────────┘               │  900μA   │
                              └──────────┘

  功耗估算（15mAh 机身 / 700mAh 充电盒）：

    使用模式              机身功耗  充电盒功耗  机身续航  充电盒续航
    ────────────────────  ────────  ──────────  ────────  ──────────
    RM RX 常驻            900μA     0.7mA       ~17h      ~1000h
    RM 推流接收           ~1mA      66mA        ~15h      ~10.5h

  优点：
  - 覆盖不受限：RM 20-56m 远超 BLE 5-11m
  - 机身逻辑最简单：有信号就放，没信号就等
  - 零切换延迟，天然不怕 BLE 断连

  缺点：
  - 机身持续 900μA-1mA，15mAh 仅 15-17h（比方案一少 ~30%）
  - 无 BLE 常连，音量/参数调节需临时建连接

  可实现性：★★☆☆☆
  机身需 RM RX 常驻 + 信号检测逻辑。充电盒改动小。

方案三：按需切换型
────────────────────────────────

  机身默认：BLE 从机（600μA），低功耗待机
  进入 RM：用户按键 或 充电盒发 BLE 指令 → 机身切 RM RX
  退出 RM：RM RX 模式 30s 无 RM 信号 → 自动切回 BLE
  充电盒：检测到音频 → 直接切 RM TX 广播（不等机身确认）

  关键：机身在 BLE 模式下功耗低（600μA），需要听音频时才切 RM RX
  充电盒不管机身状态，音频来就直接发 RM TX

  ┌──────────┐   BLE(可连可不断)┌──────────┐
  │  充电盒   │◄────────────────→│   机身   │
  │  0.7mA   │                  │ BLE 600μA│
  └──────────┘                  │ 按需切RM │
       │                         └──────────┘
       │ 检测到音频                   │ 用户按键/收到BLE指令
       │ 直接切RM TX                  ↓
       │                        ┌──────────┐
  ┌──────────┐                  │   机身   │
  │  充电盒   │═══RM TX 广播══→│ 切RM RX  │
  │  66mA    │                  │ 监听RM   │
  └──────────┘                  │  900μA   │
       │                         │ 收到RM→放音│
       │ 音频停                   └──────────┘
       │                              │ RM消失30s
  ┌──────────┐                  ┌──────────┐
  │  充电盒   │                  │   机身   │
  │  切BLE   │                  │ 切回BLE  │
  │  0.7mA   │                  │  600μA   │
  └──────────┘                  └──────────┘

  功耗估算（15mAh 机身 / 700mAh 充电盒）：

    使用模式              机身功耗  充电盒功耗  机身续航  充电盒续航
    ────────────────────  ────────  ──────────  ────────  ──────────
    BLE 待机（默认）      600μA     0.7mA       ~25h      ~1000h
    RM 推流接收           ~1mA      66mA        ~15h      ~10.5h
    典型日（30% 推流）    720μA     ~20mA       ~21h      ~35h

  优点：
  - 默认 BLE 低功耗，续航与方案一持平（~25h）
  - 进入 RM 多路径：按键（不依赖 BLE）+ BLE 指令（快速）
  - 充电盒不管机身状态，逻辑极简：音频来 → RM TX
  - 超出 BLE 范围时，用户可按机身按键主动切 RM
  - 30s 无 RM 自动回 BLE，不怕忘记切回

  缺点：
  - 用户需主动按键（或等 BLE 指令），有操作成本
  - 按键触发时充电盒可能还没开始 RM TX，机身需短暂等待
  - BLE 不在范围内时指令延迟/失败

  可实现性：★★★★☆
  在方案一基础上加按键触发 + 充电盒去掉 BLE 指令依赖。

════════════════════════════════════════════════════

方案四：占空比轮询型
────────────────────────────────

  机身默认：BLE 从机（600μA）与 RM RX（900μA）50% 占空比交替
  进入 RM：在 RM RX 窗口内检测到 RM 信号 → 锁定 RM RX，停止轮询
  退出 RM：RM RX 模式 30s 无 RM 信号 → 恢复 50% 轮询
  充电盒：检测到音频 → 直接切 RM TX 广播

  关键：机身不维持 BLE 连接，仅 BLE 广播。一半时间在 RM RX
  监听，一半在 BLE 低功耗。比方案二省电，比方案三少一次按键。

  ┌──────────┐               ┌──────────┐
  │  充电盒   │               │   机身   │
  │  0.7mA   │               │ 50% BLE  │ 600μA
  └──────────┘               │ 50% RM RX│ 900μA
       │                      │ 平均 750μA│
  检测到音频                   └──────────┘
       │                           │ RM窗口内检测到
  ┌──────────┐               ┌──────────┐
  │  充电盒   │               │   机身   │
  │  切RM TX │═══RM TX 广播══→│ 锁定RM RX│
  │  66mA    │               │  音频输出│
  └──────────┘               │  ~1mA    │
                              └──────────┘
  音频停：                         │ RM消失30s
  ┌──────────┐               ┌──────────┐
  │  充电盒   │               │   机身   │
  │  切BLE   │               │ 恢复轮询 │
  │  0.7mA   │               │  750μA   │
  └──────────┘               └──────────┘

  功耗估算（15mAh 机身 / 700mAh 充电盒）：

    使用模式              机身功耗  充电盒功耗  机身续航  充电盒续航
    ────────────────────  ────────  ──────────  ────────  ──────────
    轮询待机（50% 占空比） 750μA     0.7mA       ~20h      ~1000h
    RM 推流接收           ~1mA      66mA        ~15h      ~10.5h

  优点：
  - 不依赖 BLE 连接，覆盖范围同 RM（20-56m）
  - 比方案二省电 ~17%（900→750μA），续航多 3h
  - 无需用户操作：自动轮询，RM 窗口内检测到信号自动切换
  - 充电盒逻辑极简：音频来 → RM TX

  缺点：
  - 音频启动延迟：最坏情况需等一个轮询周期（BLE 窗口内收不到 RM）
  - BLE 不保持连接，音量/参数调节需等 BLE 窗口或手动触发
  - 轮询逻辑增加机身状态机复杂度

  可实现性：★★★☆☆
  机身需轮询调度 + RM 信号检测。充电盒改动小。
